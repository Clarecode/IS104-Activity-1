# Student Enrollment System

A responsive student enrollment dashboard based on the supplied reference images.

## Project files
- `index.html` — page structure and enrollment form
- `style.css` — dashboard, table, report, and form styling
- `script.js` — sample data, form validation, search/filter, editing, deletion, CSV export, and summary charts
- `app.py` — Python local web server

## Requirements
- Python 3
- A modern web browser
- No third-party Python packages required

## Run
1. Extract this ZIP file.
2. Open a terminal or command prompt in the extracted folder.
3. Run `python app.py` (on some systems use `python3 app.py`).
4. Open `http://127.0.0.1:8000` in your browser.

Student data is stored in the browser's local storage for that browser/device. The included 12 student records are demonstration data.
