STUDENT ENROLLMENT MANAGEMENT SYSTEM

Files:
- index.html  : page structure
- style.css   : layout and responsive design
- script.js   : form validation, student records, search, edit/delete, summary report

How to run:
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Double-click index.html or open it using Chrome, Edge, or Firefox.

Features:
- Required-field and email/age validation with inline error messages
- Unique Student ID checking
- Add, edit, and delete student records
- Search student records
- Summary cards and year-level/course counts
- Records saved in the browser using localStorage

Note:
This is a front-end demonstration. Data is stored only in the browser on the device where it is used.
