# Student Enrollment System

## Files
- `index.html` – page structure and the four Figma-inspired screens
- `style.css` – layout, colors, form styles, table, and summary report
- `script.js` – form validation, student records, search, delete, and summary calculations

## How to run
1. Download and extract the ZIP file.
2. Open the `student_enrollment_system` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or another browser.
4. Use the navigation buttons to open Student Enrollment, Student Table, and Summary Report.

## Included features
- Student enrollment form with Student ID, Full Name, Email, Age, Course, and Year Level
- Required-field, email, age, and duplicate-ID validation
- Error preview based on the Figma error design
- Student table with search and delete
- Summary cards and year-level chart that update when records change
- Browser localStorage so records remain after refreshing the page

## Important note
This is a front-end demonstration. Student information is stored in the browser on the current device only. It does not use a server or shared database.
