# Activity Submissions

Read this first before uploading your activity.

## Folder Rule

Put your files inside this structure:

```
<Program-Section>/Lastname_Firstname/ActivityNN/
```

**Examples**

```
BSIS-1A/Dela-Cruz_Juan/Activity01/
BSIS-1B/Santos_Maria/Activity02/
BSIS-1A/Reyes_Pedro/Activity01/
```

## Rules

1. **Program-Section**: use your exact program and section, e.g. `BSIS-1A`, `BSIS-1B`, `BSIS-1A`.
2. **Lastname_Firstname**: use an underscore between your last name and first name. Use a hyphen for names with spaces (e.g. `Dela-Cruz_Juan`).
3. **ActivityNN**: always use two digits: `Activity01`, `Activity02`, ... `Activity10`.
4. Put **only your own files** inside your activity folder (e.g. `.c`, `.asm`, `.txt`, screenshots).
5. Do **not** edit, move, or delete other students' folders.
6. Wrong folder name or location = **not counted** as submitted.

## Quick Checklist

- [ ] Correct section folder
- [ ] My folder is `Lastname_Firstname`
- [ ] Activity folder uses two digits (`Activity01`)
- [ ] My files are inside my activity folder
