STUDENT ENROLLMENT SYSTEM

Files:
- index.html: page structure and four interface sections
- style.css: responsive styling based on the supplied Figma screenshots
- script.js: form validation, student records, search, delete, CSV export, and summary report

How to run:
1. Extract the ZIP file.
2. Keep index.html, style.css, and script.js in the same folder.
3. Double-click index.html to open it in a browser.

Notes:
- Student records are saved in the browser using localStorage.
- This is a front-end demonstration. For a real multi-user enrollment system, connect it to a secure backend/database.
